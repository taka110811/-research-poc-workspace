## 1. 概要・解決しようとしている問題

### 背景
分散機械学習では、複数のワーカーノードが並列でデータを処理し、マスターノードがモデルを更新する。しかし一部のワーカーが**Byzantineアドバーサリ**（悪意ある攻撃者）に乗っ取られると、意図的に誤った値を送信し、学習を破壊できる。

### 問題設定
- **m台のワーカー**のうち **t台が攻撃済み**（t < m/2）
- 攻撃ノードは協調して任意の誤った値を送信できる
- マスターはどのノードが攻撃されているか知らない

### 従来手法の問題点
| 手法カテゴリ | 問題点 |
|---|---|
| 統計的ロバスト集約（geometric median等） | 統計的仮定が必要、近似誤差がΩ(√d)以上 |
| フィルタリングベース [SX19] | デコードにO(m³d)の計算コスト |
| 単純な反復符号 | ストレージ・計算コストが(2t+1)倍に増加 |

### 本論文の貢献
**データエンコーディングと実数誤り訂正**に基づく新手法を提案：
- **確定的保証**（統計的仮定不要）
- **情報理論的に最適**な耐攻撃数（最大 ⌊(m-1)/2⌋ 台）
- **定数倍のオーバーヘッド**でByztntine耐性（t ≤ m/3 の場合）

## 2. 提案手法

### コアアイデア：行列-ベクトル積（MV乗算）のエンコーディング

勾配計算はMV乗算に帰着する：
- 1ラウンド目: **Xw** を計算（X=データ行列、w=パラメータ）
- 2ラウンド目: **X^T f'(w)** を計算 → これが勾配

### エンコーディング行列 S の構造
各ワーカー i に対する疎なエンコーディング行列（ブロック構造）：
```
S_i = [0  ...  b_{1i}  ...  0  ]   ← 非ゼロ要素が (m-2t) 個以下/行
      [0  ...  b_{2i}  ...  0  ]
      ...
      [0  ...  1       ...  0  ]   ← 残りの行は1つだけ非ゼロ
```
- ワーカー i は `S_i * X` を保存（エンコード済みデータ）
- マスターは `S_i * X * w` を受け取り、**スパース誤り訂正**でXwを復元

### デコード手順（Compressed Sensingベース）
1. m台のワーカーから `S_i * Xw + e_i` を受け取る（e_iが誤り）
2. 誤りベクトルを**ランダム線形結合**でサイズmのスパース回復問題に変換
3. Reed-Solomon型デコードで誤り位置Iを特定（O(m²)時間）
4. 誠実なワーカーのデータで Xw を復元

### PGD（近似勾配降下法）アルゴリズム
```
for 各イテレーション t:
    1. マスターが w^t を全ワーカーにブロードキャスト
    2. ワーカー i が S_i^(1) * X * w^t を計算して送信
    3. マスターがデコードしてXwを復元 → f'(w^t)を計算
    4. マスターが f'(w^t)を全ワーカーに送信
    5. ワーカー i が S_i^(2) * X^T * f'(w^t)を計算して送信
    6. マスターがデコードして勾配を復元 → w^{t+1}を更新
```

### CD（座標降下法）アルゴリズム
データ行列を縦に分割してワーカーに配布：
- パラメータベクトルもエンコーディング行列Rで拡張
- 各イテレーションで一部の座標のみ更新

## 3. 主要定理と計算量

### Theorem 1（勾配計算 / PGD）

| 項目 | 計算量 |
|---|---|
| **耐攻撃数** | (s+t) ≤ ⌊ε/(1+ε) * m/2⌋ |
| **ストレージ** | 約 2(1+ε)|X| |
| **ワーカー計算量** | O((1+ε)nd/m) / イテレーション |
| **マスター計算量** | O((1+ε)(n+d)m) / イテレーション |
| **エンコード時間（1回）** | O(nd(εm/(1+ε) + 1)) |

ε はフリーパラメータ（ε=2 で t≤m/3 の耐攻撃性、定数オーバーヘッド）

### Theorem 2（座標降下 / CD）
各ワーカーが τ 座標を更新するとき：
- 各ワーカーの計算量: O(nτ)
- マスターの計算量: O((1+ε)nm + τm²)

#### Step 1: エンコーディング行列の構築
```python
import numpy as np

def build_encoding_matrix(m, t, n):
    """
    m: ワーカー数
    t: 攻撃ノード数上限
    n: データ行数
    戻り値: S (m*p × n の疎な行列)
    """
    k = 2 * t
    q = m - k          # = m - 2t
    p = int(np.ceil(n / q))
    
    # ヴァンデルモンド行列 F (エラー訂正用)
    # b_{ji} = α_i^{j-1} (相異なるα_iを選択)
    alpha = np.arange(1, m + 1, dtype=float)  # α_i = i
    
    S = []
    for i in range(m):
        S_i = np.zeros((p, n))
        for row in range(p - 1):
            start = row * q
            end = min(start + q, n)
            for idx, j in enumerate(range(start, end)):
                # b_{(idx+1), i} = alpha_i^{idx}
                S_i[row, j] = alpha[i] ** idx
        # 最後の行
        last_start = (p - 1) * q
        S_i[p - 1, last_start:n] = 1.0
        S.append(S_i)
    
    return S  # List of m個の (p × n) 行列
```

def encode_data(X, S_list):

    encoded = []
    for S_i in S_list:

```python
def run_gd_experiment(n=10000, d=250, m=15, t=3, max_iter=100):
    """Byzantine耐性GDの実験"""
    # データ生成
    X = np.random.randn(n, d)
    theta_true = np.zeros(d)
    theta_true[np.random.choice(d, d//3)] = np.random.randn(d//3) * 2
    y = X @ theta_true + np.random.randn(n)
    
    # エンコーディング
    S_list = build_encoding_matrix(m, t, n)
    encoded_X = encode_data(X, S_list)
    
    # GDループ
    w = np.zeros(d)
    lr = 1e-4
    losses = []
    
    for iteration in range(max_iter):
        # 1. 各ワーカーがS_i @ X @ wを計算（一部は攻撃値を送信）
        responses = []
        corrupt_idx = np.random.choice(m, t, replace=False)
        for i in range(m):
            true_val = encoded_X[i] @ w
            if i in corrupt_idx:
                # 攻撃ノード: N(0, 100^2)のノイズを加算
                true_val += np.random.randn(len(true_val)) * 100
            responses.append(true_val)
        
        # 2. Byzantine耐性デコードでXwを復元
        Xw = byzantine_decode(responses, S_list, m, t)
        
        # 3. 勾配を計算してwを更新
        # gradient = X^T (Xw - y) / n
        grad = X.T @ (Xw - y) / n
        w -= lr * grad
        
        loss = np.mean((X @ w - y) ** 2)
        losses.append(loss)
    
    return w, losses
```

## 7. 制約・限界

| 制約 | 内容 |
|---|---|
| **攻撃数の上限** | t < m/2 が必須（情報理論的限界） |
| **適用範囲** | 一般線形モデル（GLM）のみ（非線形モデルへの直接適用不可） |
| **ストレージ** | t が m/2 に近づくとO(m)倍に増加 |
| **マスターの計算** | tが増えるほど計算コストが増加（t=7で急増） |
| **データ分布の仮定** | なし（任意のデータに対応）← 逆に強み |
| **実装の複雑さ** | Reed-Solomon型デコードの実装が必要 |
